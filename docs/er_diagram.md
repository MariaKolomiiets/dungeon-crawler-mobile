# ER-діаграма та структура бази даних

Нижче наведено концептуальну схему збереження ігрового стану та прогресу для мобільної гри на Godot Engine.

## Основні сутності та атрибути:
1. **Player (Гравець):**
   - `player_id` (PK) — унікальний ідентифікатор сесії.
   - `current_hp`, `max_hp` — поточний та максимальний запас здоров'я героїні.
   - `current_floor_id` (FK) — посилання на поточний поверх підземелля.
   - `position_x`, `position_y` — координати персонажа.

2. **Floor (Поверх підземелля):**
   - `floor_id` (PK) — унікальний ідентифікатор поверху.
   - `floor_number` — порядковий номер поверху.
   - `seed_value` — значення для процедурної генерації.

3. **Room (Кімната):**
   - `room_id` (PK) — унікальний ідентифікатор кімнати.
   - `floor_id` (FK) — посилання на поверх.
   - `room_type` — тип кімнати (звичайна, торговець, бос).

4. **Enemy (Противник):**
   - `enemy_id` (PK) — унікальний ідентифікатор ворога.
   - `room_id` (FK) — посилання на кімнату.
   - `health_points` — поточне здоров'я ворога.
   - `is_boss` — ознака боса.

5. **Spell (Закляття):**
   - `spell_id` (PK) — унікальний ідентифікатор закляття.
   - `spell_name` — назва здібності.
   - `damage` — сила завданюваної шкоди.
