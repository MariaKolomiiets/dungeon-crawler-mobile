# Godot 3D Top-Down Dungeon Crawler

## Загальна інформація про систему
**Dungeon Crawler** — це мобільна Action-RPG гра, розроблена на ігровому рушії Godot Engine 4 з використанням мови GDScript для пристроїв під управлінням ОС Android. Проєкт реалізує автономне проходження процедурно згенерованих підземель, сенсорне керування рухом героїні, тактичні бої в реальному часі та локальне збереження ігрового прогресу.

## Архітектурний патерн
У проєкті реалізовано **багаторівневу архітектуру з послабленою ізоляцією рівнів (N-Layer with Relaxed Layering)**, що забезпечує високу продуктивність і стабільний FPS на мобільних пристроях:
- **Presentation Layer:** Сцени Godot, камери, HUD, віртуальний джойстик та сенсорні кнопки.
- **Application Layer:** Менеджер ігрової сесії, процедурний генератор поверхів, координатор бойових зіткнень.
- **Domain Layer:** Чисті класи сутностей (сутності гравця, ворогів, босів, логіка заклять та розрахунок шкоди).
- **Infrastructure / Data Layer:** Менеджер ресурсів (меші, текстури, аудіо) та модуль локального збереження.

## Основні функціональні можливості (Use Cases)
- **Дослідження підземель:** Генерація унікальних кімнат, коридорів та переміщення персонажа за допомогою сенсорного джойстика.
- **Бойова система та AI:** Ведення бою в реальному часі проти ворогів і босів, чия поведінка керується скінченними автоматами (FSM), застосування спеціальних навичок.
- **Взаємодія з об'єктами:** Відкриття скринь, взаємодія з торговцями, отримання нових предметів та екіпірування.
- **Збереження прогресу:** Автоматична фіксація стану здоров'я, координат, відкритого поверху та інвентарю у локальній базі даних / файлах.

## Структура бази даних (ER-Model)
Концептуальна схема збереження ігрового стану охоплює такі ключові сутності:
- `Player` — фіксує поточний і максимальний запас HP, координати (`position_x`, `position_y`) та активний поверх (`current_floor_id`).
- `Floor` та `Room` — параметри процедурної генерації (номер поверху, унікальний `seed_value`, статуси зачищення кімнат `is_cleared`).
- `Enemy` — вороги та боси із зазначенням типу, поточного рівня здоров'я та стану життя.
- `GameObject` — об'єкти середовища (скрині, торговці, вівтарі).
- `Spell` та `PlayerSpell` — каталог доступних заклять і зв'язок M:N між гравцем та його активними здібностями.

## Інтерфейс користувача (UI/UX)
Інтерфейс застосунку спроєктований для зручного керування на сенсорних екранах смартфона:
1. **Головне меню:** Кнопки «Нова гра / Продовжити», «Налаштування» та «Вихід».
2. **Основний ігровий екран:** Інформаційна панель зі здоров'ям (`HP`), міні-карта поверху, віртуальний джойстик переміщення ліворуч та кнопки атаки/заклять праворуч.
3. **Вікно взаємодії:** Спливаюче меню для вибору товарів у торговця або огляду вмісту відкритих скринь.
4. **Меню паузи:** Збереження стану ігрової сесії та вихід до головного меню.

## Спосіб запуску проєкту
### Варіант 1: Для користувачів (інсталяція готового APK)
1. Перейдіть до розділу **Releases** репозиторію та завантажте останній зкомпільований файл `dungeon_crawler.apk`.
2. Встановіть застосунок на ваш Android-пристрій та розпочніть гру.

### Варіант 2: Для розробників (через Godot Editor)
1. Клонуйте репозиторій на локальний комп'ютер:
